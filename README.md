# ratekeeper


 

A distributed rate limiter built with **Python, FastAPI and Redis**: a small service

that answers *"may this user do this right now?"* for any number of app instances,

with exact limits enforced in Redis.


 

- **Four algorithms** behind one API: fixed window, sliding log, sliding counter, GCRA ([how they work](docs/ALGORITHMS.md))

- **Exact and atomic:** each check is one Lua script in Redis using whole-number microsecond math; no floats, no races

- **Proven, not just tested:** a Python reference model, Hypothesis property tests of its guarantees, and a test that real Redis returns identical decisions for thousands of random scenarios

- **Several limits per policy** ("10/second **and** 1000/hour"), all-or-nothing, with variable request cost

- **Survives outages:** timeouts, a circuit breaker, and a per-policy choice to fail open or closed when Redis is down

- **Versioned policies** in Postgres with history and optimistic locking (ETag / If-Match), cached in memory so the hot path never waits on the database

- **Observable:** Prometheus metrics, liveness/readiness/health endpoints


 

Every design choice, its alternatives and the reasons are in [docs/DESIGN.md](docs/DESIGN.md).


 

## Quick start


 

Requires Python 3.12+, [uv](https://docs.astral.sh/uv/) and Docker.


 

```bash

uv sync                                  # create .venv, install everything (first run also writes uv.lock: commit it)

docker compose up -d redis postgres      # databases only

uv run alembic upgrade head              # create the tables

uv run uvicorn ratekeeper.main:app --reload

```


 

The API is at http://localhost:8000; interactive docs at http://localhost:8000/docs.


 

Or run everything, with two app instances on ports 8001 and 8002 sharing one Redis:


 

```bash

docker compose up --build -d

```


 

## Using it


 

**1. Create a policy:** 5 requests per minute *and* 100 per hour, GCRA, fail closed.


 

```bash

curl -X PUT localhost:8000/v1/policies/login \

  -H 'Content-Type: application/json' \

  -d '{

        "algorithm": "GCRA",

        "failure_mode": "CLOSED",

        "bands": [

          {"limit": 5,   "window": "PT1M"},

          {"limit": 100, "window": "PT1H"}

        ]

      }'

```


 

Windows are ISO-8601 durations: `PT1S`, `PT1M`, `PT1H`, `P1D`. The response has

`ETag: "1"`, the policy version.


 

**2. Check a request:**


 

```bash

curl -X POST localhost:8000/v1/check \

  -H 'Content-Type: application/json' \

  -d '{"policy": "login", "identity": "user-42"}'

```


 

```json

{"allowed": true, "degraded": false, "policy": "login", "identity": "user-42",

 "limit": 5, "remaining": 4, "reset_after_ms": 12000, "retry_after_ms": 0}

```


 

Headers: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` (seconds),

and `Retry-After` (seconds) when rejected. The status is `200` whenever the check

worked; your gateway turns `allowed: false` into a `429` for its own client

([why](docs/DESIGN.md#15-v1check-returns-200-with-the-decision-in-the-body)).


 

Optional `"cost": 10` consumes 10 units at once.


 

**3. Update safely:** `If-Match` stops you overwriting someone else's change.


 

```bash

curl -X PUT localhost:8000/v1/policies/login -H 'If-Match: "1"' -H 'Content-Type: application/json' -d '...'

```


 

### Endpoints


 

| Method | Path | |

|---|---|---|

| `POST` | `/v1/check` | Consume quota; returns the decision |

| `PUT` | `/v1/policies/{name}` | Create (201) or replace (200); safe to repeat |

| `GET` | `/v1/policies/{name}` | One policy, with ETag |

| `GET` | `/v1/policies` | All policies |

| `DELETE` | `/v1/policies/{name}` | Delete (optional If-Match) |

| `GET` | `/v1/policies/{name}/history` | Every change, newest first |

| `GET` | `/metrics` | Prometheus metrics |

| `GET` | `/health`, `/health/live`, `/health/ready` | Health |

| `GET` | `/docs` | Interactive API docs (generated by FastAPI) |


 

Errors use problem-details JSON: `{"status": 404, "title": "Not Found", "detail": "..."}`.


 

## Configuration


 

Environment variables (or a `.env` file), all prefixed `RATEKEEPER_`:


 

| Variable | Default |

|---|---|

| `RATEKEEPER_REDIS_URL` | `redis://localhost:6379/0` |

| `RATEKEEPER_DATABASE_URL` | `postgresql+asyncpg://ratekeeper:ratekeeper-local-dev@localhost:5432/ratekeeper` |

| `RATEKEEPER_REDIS_TIMEOUT_SECONDS` | `0.1` |

| `RATEKEEPER_POLICY_CACHE_REFRESH_AFTER_SECONDS` | `30` |

| `RATEKEEPER_BREAKER_OPEN_SECONDS` | `5` |


 

All settings: [src/ratekeeper/config.py](src/ratekeeper/config.py).


 

## Tests


 

```bash

uv run pytest -m "not integration"   # unit + property tests; no Docker needed

uv run pytest                        # everything, incl. real Redis/Postgres in Docker

uv run ruff check && uv run mypy     # lint + type-check

```


 

| Test | Proves |

|---|---|

| `test_reference_properties.py` | Never over-admits; `retry_after`/`reset_after` exact to the µs; rejections charge nothing |

| `integration/test_redis_equivalence.py` | Lua in real Redis = reference model, decision for decision |

| `integration/test_redis_behaviour.py` | 500 concurrent requests at limit 50 → exactly 50 admitted; keys expire |

| `test_check_service.py`, `test_breaker.py`, `test_policy_cache.py` | Fail-open/closed, circuit breaker, cache freshness and races |

| `integration/test_api.py` | The full HTTP API end to end |


 

## Project layout


 

```

src/ratekeeper/

  core/            domain: models, validation rules, Redis key layout (no framework imports)

  lua/             prelude.lua (shared) + one script per algorithm

  redis_limiter.py runs the Lua scripts

  check/           hot path: circuit breaker + CheckService

  policies/        Postgres repository, versioned writes, in-memory cache + pub/sub

  api/             FastAPI routes, request/response models, error mapping, health

  main.py          app factory: wires everything at startup

  config.py        settings from environment variables

migrations/        Alembic migrations

tests/             unit tests, reference model, Hypothesis strategies

tests/integration/ tests against real Redis/Postgres (Docker)

docs/              DESIGN.md, ALGORITHMS.md, ROADMAP.md

```
